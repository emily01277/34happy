# 趙岑 (Zhao Cen) - 個人介紹與履歷網頁

> 「開心開心」—— 保持好奇，開心生活 ✨

一個採用純 HTML5 / CSS3 / Vanilla JavaScript 打造的現代極簡風個人履歷與自我介紹網頁，支援全響應式版面、捲動淡入動畫與即時主題色系切換。

## 🌟 特色亮點
- **響應式設計**：完美適配手機、平板與桌機。
- **主題調色盤**：內建 4 種主題配色（森林綠、謐境藍、晨曦橘、活力紫）即時切換。
- **流暢動效**：純 CSS + IntersectionObserver 打造滑順淡入上浮動畫。
- **單檔結構**：無任何外部框架相依，開啟 `index.html` 即可瀏覽。

## 🚀 如何使用
直接使用任何瀏覽器開啟 `index.html` 即可瀏覽。
